# v2.3.0-alpha.1

这是 FV-JDBJU2-S 适配的首个预发布版本。实现依据松下 App 源码静态分析，尚未完成实机验证，供设备联调使用。自动化测试通过不代表设备协议已经验证。

## 新增

- 识别 `FV-JDBJU2-S` 和 `JDBJU2-S`，提供待机、取暖、换气、凉干燥、热干燥模式。
- 提供固定/自动风向、集中/扩散送风、运行时长及剩余时间。运行时长用于定时停止，不包含预约启动。
- 运行时长选项随模式变化：取暖最长 3 小时，热干燥最长 6 小时，换气和凉干燥提供连续运行选项。
- 气味感应按设备返回的硬件标志创建；换气风量作为实验性实体提供，默认禁用。
- 提供报警、滤网、固件更新状态码等诊断实体，以及将控制项放在一张原生 HA 卡片中的示例。
- 每台新型号设备共享一份状态并统一轮询；控制操作串行执行，发送后读取设备状态。重复设置当前模式不会重置倒计时。

JDBJU2-S 不创建照明或音响实体。型号差异和功能限制由 profile 声明，现有空调和 RB20VL1 保留原有控制路径。

## 修复

- 重扫已有设备时，名称和型号信息的变化能够被正确保存，并保留用户设置。
- 顶层成功码不再掩盖嵌套业务错误；认证错误优先触发重新登录。
- 登录和设备列表响应的异常结构转换为统一 API 错误，避免未处理异常导致配置流程失败。

## 已验证与待验证

- 170 条自动化测试全部通过，覆盖型号匹配、控制参数、共享状态、HA 实体及生命周期、异常响应和既有型号回归场景。
- Ruff 静态检查、格式检查及 Python 编译检查通过。
- 实际设备发现、云端控制、状态回读与各模式行为仍需实机确认。
- 送风方式在 App 主页面与参数对话框中的编码含义存在矛盾；当前采用对话框的读写映射，需确认集中/扩散是否一致。
- App 对该型号隐藏换气风量控件，设备是否接受此控制尚待确认。
- 测试环境为 Home Assistant Core 2026.10.1；最低声明版本为 2026.8.0，尚未在该最低版本运行完整验证。

## 安装

最低要求为 Home Assistant Core 2026.8.0。

1. 在 HACS 添加自定义仓库 `iavjkae/panasonic_smart_china`，类别选择 **Integration**。
2. 在 HACS 中显示预发布版本并选择 `v2.3.0-alpha.1`，安装后重启 Home Assistant。

设备识别或功能行为异常时，请提供脱敏后的设备列表、状态和错误日志，移除账号、SSID、token 等凭据。
